# vehicle-makes-models data license

The generation facts in `vehicle_generations.json` are derived from the
`vehicle-makes-models` dataset at commit
`b4965631140fa82404359167621274601da69a5b`.

That dataset is licensed under the Open Database License (ODbL) 1.0:
https://opendatacommons.org/licenses/odbl/1-0/

Attribution: vehicle-makes-models, https://github.com/gor3a/vehicle-makes-models,
with autoevolution.com named by that project as its upstream source. AutoMind
matches those source records to its larger make/model catalog and adds fallback
generation rows; these are modifications to the source database.

The ODbL permits sharing, creating from, and adapting the database subject to
attribution, share-alike, and keep-open requirements. This notice is a summary;
the canonical ODbL 1.0 license linked above controls.
