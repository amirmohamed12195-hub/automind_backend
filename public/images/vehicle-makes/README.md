# Vehicle make logos

This directory contains the 184-logo automotive make set curated by
[VehicleSpecs.io](https://github.com/vehiclespecs/brand-logos), pinned from
commit `3f0929e70e0a9a2a502063edc4b3e5c0146cba74`.

The repository metadata and curation are provided under the MIT License. The
logos themselves remain trademarks of their respective owners and are used
only to identify vehicle makes. See `LICENSE` for the full notice.

The assets are designed for display on a white or very light neutral
background.
